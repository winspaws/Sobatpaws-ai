# Scurvy (Defisiensi Vitamin C)

## Ringkasan

Marmut tidak bisa sintesis vitamin C, sehingga defisiensi menyebabkan gangguan kolagen, sendi & gusi.

## Etiologi & Patofisiologi

| Field | Nilai |
|-------|-------|
| Etiologi | nutritional |
| Sistem tubuh | musculoskeletal |
| Menular | tidak |
| Zoonosis | tidak |
| Tingkat keparahan | moderate |
| Darurat | tidak |

## Penyebab

Diet kurang vitamin C, pelet kadaluwarsa (vit C terdegradasi).

Suplementasi vitamin C harian, sayuran segar (paprika), pelet khusus marmut segar.
