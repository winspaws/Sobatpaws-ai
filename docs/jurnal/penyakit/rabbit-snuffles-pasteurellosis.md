# Snuffles (Pasteurellosis)

## Ringkasan

Infeksi saluran napas atas oleh Pasteurella multocida, sering kronik.

## Etiologi & Patofisiologi

| Field | Nilai |
|-------|-------|
| Etiologi | infectious_bacterial |
| Sistem tubuh | respiratory |
| Menular | ya |
| Zoonosis | tidak |
| Tingkat keparahan | moderate |
| Darurat | tidak |

## Penyebab

Pasteurella multocida; dipicu stres, ventilasi buruk, amonia kandang.

## Pencegahan

Kandang bersih & berventilasi baik, kurangi stres, isolasi penderita.

## Prognosis

Sulit eradikasi total; manajemen jangka panjang.
