# Koksidiosis (Berak Darah)

## Ringkasan

Infeksi protozoa Eimeria pada usus, umum pada ayam muda di litter lembap.

## Etiologi & Patofisiologi

| Field | Nilai |
|-------|-------|
| Etiologi | parasitic_internal |
| Sistem tubuh | digestive |
| Menular | ya |
| Zoonosis | tidak |
| Tingkat keparahan | severe |
| Darurat | tidak |

## Penyebab

Eimeria spp.; litter basah, kepadatan tinggi, sanitasi buruk.

|-----|------|---------------|--------|

| Nekropsi usus | necropsy | tidak | Perdarahan/lesi sekum/usus |

## Pencegahan

Litter kering, kepadatan tepat, koksidiostat dalam pakan, vaksin coccidia.

## Prognosis

Baik bila diobati dini; kerugian berat bila terlambat.
