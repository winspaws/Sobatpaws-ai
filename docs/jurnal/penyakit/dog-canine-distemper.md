# Distemper (Carre)

## Ringkasan

Virus multisistem menyerang saluran napas, cerna, dan saraf; sering fatal pada anak anjing.

## Etiologi & Patofisiologi

| Field | Nilai |
|-------|-------|
| Etiologi | infectious_viral |
| Sistem tubuh | systemic |
| Menular | ya |
| Zoonosis | tidak |
| Darurat | ya |

## Penyebab

Canine Distemper Virus (paramyxovirus) via aerosol & sekret.

Variabel; gejala neurologis menandakan prognosis buruk.
