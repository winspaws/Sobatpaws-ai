# Kantung Pipi Tersumbat

## Ringkasan

Makanan/bedding menumpuk & tersangkut di kantung pipi, bisa infeksi (abses).

## Etiologi & Patofisiologi

| Field | Nilai |
|-------|-------|
| Etiologi | traumatic |
| Sistem tubuh | digestive |
| Menular | tidak |
| Zoonosis | tidak |
| Tingkat keparahan | mild |
| Darurat | tidak |

## Penyebab

Makanan lengket, bedding berserat, luka kantung pipi.

## Pencegahan

Hindari makanan lengket & bedding kapas, sediakan bedding aman.

## Prognosis

Baik bila dibersihkan; abses butuh penanganan lebih.
