# Panleukopenia (Distemper Kucing)

## Ringkasan

Parvovirus kucing menyerang sumsum tulang & usus; sangat fatal pada anak kucing.

## Etiologi & Patofisiologi

| Field | Nilai |
|-------|-------|
| Etiologi | infectious_viral |
| Sistem tubuh | digestive |
| Menular | ya |
| Zoonosis | tidak |
| Tingkat keparahan | critical |
| Darurat | ya |

## Penyebab

Feline Panleukopenia Virus (FPV) via feses/lingkungan, sangat tahan lama.

## Pencegahan

Vaksin tricat (FPV/FHV/FCV), disinfeksi, isolasi.

## Prognosis

Mortalitas tinggi pada kitten; survival membaik dengan rawat intensif.
