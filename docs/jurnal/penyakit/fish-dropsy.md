# Dropsy (Sisik Nanas / Asites)

## Ringkasan

Penumpukan cairan tubuh menyebabkan perut bengkak & sisik berdiri (pinecone); tanda gagal organ/infeksi sistemik.

## Etiologi & Patofisiologi

| Field | Nilai |
|-------|-------|
| Etiologi | infectious_bacterial |
| Sistem tubuh | systemic |
| Menular | tidak |
| Zoonosis | tidak |
| Tingkat keparahan | critical |
| Darurat | tidak |

## Penyebab

Infeksi bakteri sistemik (Aeromonas), gagal ginjal, kualitas air buruk, imunitas turun.

## Pencegahan

Kualitas air prima, pakan berkualitas, hindari stres kronik.

## Prognosis

Buruk (sering terlambat); pengobatan dini meningkatkan peluang.
